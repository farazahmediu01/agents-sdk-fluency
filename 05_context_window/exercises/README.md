# Chapter 5 — your workspace

Track 1 drills go here. See [`../EXERCISES.md`](../EXERCISES.md).

Nothing in this folder is imported by the project or graded. It **is** held to the same
quality gate as everything else — `ruff`, `pyright` and `pytest` all run over it, on purpose:
a curriculum that exempts student code from its own standards is teaching that the standards
are decoration.

Suggested filenames, matching the exercise numbers:

| File | Exercise |
|---|---|
| `dungeon.py` | 1 — the dungeon master forgets your name |
| `noisy_tool.py` | 2 — a tool that will not shut up |
| `interview_coach.py` | 3 — **blank-file challenge, mandatory** |
| `test_my_trim.py` | 6 — prove your trimmer, offline |

Exercise 3 starts from an empty file. Do not open `../solutions/` first; looking feels
efficient and teaches nothing.
